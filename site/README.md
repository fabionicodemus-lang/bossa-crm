# Bossa Site 2.0

Site institucional e comercial da Bossa Empreendimentos (Next.js). Fica nesta pasta `site/`,
separado do CRM (raiz do repositório), para que cada um seja publicado e evolua sozinho.

- Conteúdo: `src/content/` (empreendimentos, textos, perguntas).
- Medição: `src/lib/eventos.ts`, `src/lib/rastreio.ts`, `src/app/api/`.
- Banco: `supabase/migrations/` (já aplicada no projeto bossa-crm em 17/10/2026).
- Variáveis: ver `.env.example`.
